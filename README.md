# CASEFORM — магазин чохлів

## Запуск локально
1. Встановіть Node.js 18 або новіший.
2. У папці проєкту виконайте `npm install`.
3. Створіть Telegram-бота через BotFather.
4. Напишіть боту `/start`, щоб він міг надсилати вам повідомлення.
5. Дізнайтеся свій Telegram chat_id (наприклад, через службового бота для отримання ID).
6. Запустіть сервер із секретними змінними середовища:
   - `TELEGRAM_BOT_TOKEN` — токен бота (нікому не надсилайте й не вставляйте у frontend).
   - `TELEGRAM_CHAT_ID` — ваш числовий chat_id.
7. Виконайте `npm start` і відкрийте `http://localhost:3000`.

## Важливо
- `@zwiph` — це username, але Telegram Bot API надсилає повідомлення за chat_id. Потрібно відкрити бота й натиснути Start; серверу потрібні токен бота та chat_id.
- Онлайн-оплата Visa/Mastercard, Apple Pay, Google Pay та криптовалютою в макеті показана як варіанти, але не приймає гроші. Для запуску треба укласти договір/створити акаунт у платіжного провайдера та додати серверну перевірку платежів.
- Накладений платіж і передоплата 100 грн зараз записуються як обраний спосіб у заявці; фактичні розрахунки узгоджуються з покупцем.
- Перевірте фактичну звичайну ціну 450 грн перед публікацією рекламної заяви про знижку.
- Додані фотографії взяті з наданих вами зображень.
